# PlebCross

A NYT-style crossword replica with a built-in coach: click any clue and get three
progressively revealing hints, generated by Gemini, ending with an optional
answer + explanation reveal. Historic and pop-culture references in clues get a
one-sentence gist so solving doubles as learning.

Includes an original 13x13 "daily-style" puzzle (70 entries, symmetric grid,
no unchecked squares) to demo the full experience — this app can't fetch the
actual daily NYT puzzle, since it's subscriber-only with no public API, so
the grid, clues, and answers here are hand-authored. The grid itself was
generated with a constraint solver (verified for symmetry, fully-checked
cells, and no duplicate answers) rather than filled by hand, to guarantee a
valid crossword; clues were then written by hand for each entry.

## Getting started

```bash
npm install
cp .env.local.example .env.local   # add your GEMINI_API_KEY
npm run dev
```

Get a free Gemini API key at [aistudio.google.com/apikey](https://aistudio.google.com/apikey).

Open [http://localhost:3000](http://localhost:3000).

## How it works

- `src/lib/puzzle.ts` — the puzzle grid, clues, and answer key (server-only,
  never shipped to the client).
- `src/lib/hints.ts` — calls the Gemini API with the clue + correct answer and
  asks for 3 progressive hints (with reference gists) plus a post-solve
  explanation, via a JSON response schema for structured output. Results are
  cached in memory per clue.
- `src/app/api/{hints,reveal,check}` — route handlers the client calls; the
  answer itself is only ever sent to the client from `/api/reveal`, when the
  user explicitly asks for it.
- `src/components/CrosswordApp.tsx` — grid state, keyboard navigation, and
  wiring between the grid, clue lists, and hint panel.

## Deploying

This is a stock Next.js app, so it deploys to
[Vercel](https://vercel.com/new) with zero config: import the repo, add a
`GEMINI_API_KEY` environment variable in the project settings, deploy.

## Notes

- The hint cache is in-memory per server process — fine for local/dev use,
  but resets on restart or across serverless instances.
- To use your own puzzle, edit the `GRID_ROWS`/`ACROSS_CLUES`/`DOWN_CLUES`
  constants in `src/lib/puzzle.ts`.
