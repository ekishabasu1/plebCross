# PlebCross

A NYT-style crossword replica with a built-in coach: click any clue and get three
progressively revealing hints, generated by Claude, ending with an optional
answer + explanation reveal. Historic and pop-culture references in clues get a
one-sentence gist so solving doubles as learning.

Includes a small original 5x5 "mini" puzzle to demo the experience end to end
(this app can't fetch the actual daily NYT puzzle — it's subscriber-only with
no public API — so the grid, clues, and answers here are hand-authored).

## Getting started

```bash
npm install
cp .env.local.example .env.local   # add your ANTHROPIC_API_KEY
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## How it works

- `src/lib/puzzle.ts` — the puzzle grid, clues, and answer key (server-only,
  never shipped to the client).
- `src/lib/hints.ts` — calls the Claude API with the clue + correct answer and
  asks for 3 progressive hints (with reference gists) plus a post-solve
  explanation, via tool-use for structured output. Results are cached in
  memory per clue.
- `src/app/api/{hints,reveal,check}` — route handlers the client calls; the
  answer itself is only ever sent to the client from `/api/reveal`, when the
  user explicitly asks for it.
- `src/components/CrosswordApp.tsx` — grid state, keyboard navigation, and
  wiring between the grid, clue lists, and hint panel.

## Notes

- The hint cache is in-memory per server process — fine for local/dev use,
  but resets on restart or across serverless instances.
- To use your own puzzle, edit the `GRID_ROWS`/`ACROSS_CLUES`/`DOWN_CLUES`
  constants in `src/lib/puzzle.ts`.
